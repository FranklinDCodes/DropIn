
The goal is to push the neurons in a given layer apart so as to maximize model capacity
Instead of using dropout, I think this is ideal to maximize capacity-per-computation along with some other type of regularization (data noising perhaps)

First I tried randomly boosting weights during training, but this seemed to not help.
In the config, this is called drop-in
All the configs for this are in gen_01

Next, I want to use Kaiming init but distribute the variance so that weights within a given neuron are similar, 
but neuron to neuron there is large variance for any given feature. 
I'll call this InterNVG_init (Inter-neuron variance Glorot init), 
meaning high variance among/between neurons, not within
After config 10, all models are using Glorot init by default
This is all gen_02

gen_03 is like gen_02 but made for mnist


Other ideas include a -log mean neuron output signal variance for each hidden layer term in the loss,
